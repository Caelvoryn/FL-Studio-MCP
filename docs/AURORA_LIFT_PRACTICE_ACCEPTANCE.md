# Aurora Lift：真实 FL Studio 音乐制作实战验收

日期：2026-10-29；环境：Windows、FL Studio 26.1.5 build 5618；开发分支 codex/pianoteq-direct。

## 交付与音乐

已通过独立 stdio MCP 在真实 FL Studio 完成原创 32 小节，128 BPM，A minor。正文 60 秒，包含 Intro（1–8）、Build-up（9–16）、Drop（17–28）、Outro（29–32）。Am–F–C–G 和声，钢琴分解与切分和弦、带变化的主旋律、反拍 Bass、Kick/Snare/开闭镲及过渡填充。

主要工程：Aurora Lift - Verified Reopened.flp；原始完成版 Aurora Lift - Final.flp 也保留。音频见独立成品目录中的 Aurora Lift - Final.wav、Aurora Lift - Same Session.wav、Aurora Lift - Reopened.wav。工程基于此前技术验收模板副本创作，未声称本次从空白启动；未修改 Skyline、默认 MCP 配置或已安装控制器。

Pianoteq 9 钢琴、Sylenth1 主旋律、Sytrus Bass、FPC 鼓组。Pianoteq 使用继承的已验收 Steinway B Bright 设置；没有据参数变化推测 Sylenth1 内部预设名称。实际编排音符 884 个；8 个 MIDI Pattern 共保存 1329 音符，其中4个拆分鼓组 Pattern 未放入 Playlist，仅保留编辑备用。Playlist 使用4条长乐器 Pattern及1条自动化片段，段落变化写在 Pattern内部，不是逐段短片段排列。同乐器 Pattern 重叠为0。

## 实际操作与证据

- 直接宿主接口：BPM、实例/参数读取、批量参数写入和独立回读、Mixer 分轨/音量/声像。Pianoteq/Mixer/效果器状态保存重开后重新读取。
- 原生键盘/UIA辅助：插件选择器、MIDI导入、Pattern选择、保存/重开。音符不是通过直接 Score CRUD API 写入，而是实际 FL MIDI 导入后读取原生 FLP 检查。
- 有限 GUI 辅助：Playlist放置、菜单、自动化节点、导出设置采用观察后的窗口相对目标，含截图校准和鼠标操作。本次没有实现全程无坐标，不将 GUI 输入收据视为验证成功。
- Piano/Lead/Bass/Drums 分配 Mixer 1/2/3/4；基础音量/声像平衡。Lead 链实际加载 Fruity parametric EQ 2、Compressor、Reeverb 2、delay 2。压缩阈值−12 dB、比率1.6:1、Attack10ms、Release151ms；Delay输入10%、Dry100%、反馈实际25%、Time3:00、P.Pong、Cutoff66%。这不是完整母带处理；未逐个效果器做旁路听感对照。
- 鼓组音量自动化：0拍约0.67，112拍约0.667，128拍0。保存前及重开后，播放到约120拍均实际回读到下降的Mixer音量；不只根据曲线文件宣称有效。
- 实际保存、重开、再次另存，再次通过真实FL导出窗口渲染。原生音符/通道/自动化/插件状态哈希/Mixer事件哈希均一致。Playlist原始实例ID变化，排除实例ID后的语义状态一致。
- 真实重叠防护：对已有Pattern尝试复制到同轨同位置，返回 PLAYLIST_OVERLAP_RISK，未创建目标文件。另一次选择到自动化片段的复制请求返回 UNSUPPORTED_CLIP，未计作成功。
- 203项离线回归通过（5个警告，19.35秒）；它们与真实FL证据分开记录，不能代替宿主测试。

## 音频数值验收

三份均为44.1kHz、立体声、PCM16，有限数值、削波样本0。正文前60秒，以100ms块、−70dBFS阈值检查，无连续静音块。

|同会话重复|62.128912秒|−6.5226|−23.7678|

Final各段RMS：Intro−26.81、Build−22.68、Drop−21.74、Outro−24.14dBFS；Drop比Intro约高5.1dB。尾部100ms峰值约−84至−90dBFS，未发现数值上的明显硬截断。未测LUFS/真峰值，不作商业母带质量宣称。

PCM不完全一致，尾音时长也不同。统一比较前60秒：Final与同会话重复的差分RMS−22.923dBFS、整体电平差−0.483dB；Final与重开后差分RMS−23.038dBFS、电平差−0.617dB。同会话重复与重开后电平差−0.134dB。工程状态一致、同会话重复也有类似差异，与运行时非确定性相符，但尚未隔离具体合成器/效果器原因，不能证明听感完全等价，也不能宣称PCM一致性验收通过。

已产生真实可解码WAV；模型未进行可靠主观听评。旋律记忆点、律动、音色审美与高潮冲击力仍待用户实际试听。

## 修复与剩余限制

实际故障推动的小范围修复包括：隐藏Playlist的快捷键定位；原生保存后的候选会话所有权同步；Pattern选择计数/名称核验；本地化插件加载占位名称识别；仅打开导出窗口与完成渲染分离；菜单指针操作前避免焦点切换导致菜单消失；参数写一次后限时只读等待；支持FL保存时清除的普通音符导入标记。

最初同音高重叠被MIDI导入截短，去除同音高重叠后逐音符复核；早期自动化菜单未创建曲线，保留失败检查点，后续真实创建并验证。参数量化导致部分请求返回READBACK_MISMATCH，没有放宽测试容差或伪报成功；独立读取实际25%/66%后采用该创作设置，并验证持久化。渲染文件尚被占用时的解码失败在真正完成渲染后复核通过。

Channel Rack过滤会影响插件索引识别，切回All后再核验。第三方自绘界面、所有插件预设通用切换、任意自动化与Playlist无坐标编辑仍不属于通用已验收能力。现有依赖安全审计遗留事项仍见仓库SECURITY_REVIEW.md，本次音乐实测不代表该审计完成。

完整输入、返回、状态和测试日志保留在本地交付目录“验收记录”；早期失败检查点保留，不能依据文件名判断功能成功。FLP和商业插件状态、音频保留本地，不作为源码发布附件。
